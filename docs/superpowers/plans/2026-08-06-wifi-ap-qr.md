# WiFi AP + QR Join Code Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Declare Alice's WiFi access point (hostapd + dnsmasq) in the NixOS flake, and add an on-demand alias that generates a printable QR code visitors can scan to join.

**Architecture:** Two new NixOS modules (`wifi-ap.nix`, `aliases.nix`) plus a committed example credentials file. The WiFi password lives only in `/etc/alice/wifi-credentials` on the target machine (never in git, never in the Nix store) — both `hostapd` and the `wifi-qr` script read it at runtime via small shell scripts, not through Nix's option system.

**Tech Stack:** NixOS (25.05), `hostapd`, `dnsmasq`, `qrencode`, bash.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-06-wifi-ap-qr-design.md`
- SSID/password must never appear in git or in `/nix/store` — only in `/etc/alice/wifi-credentials` on the machine, mode `600`.
- No `nix`/`nixos-rebuild` toolchain is available on this dev machine (macOS, confirmed via `which nix`). Flake-evaluation steps below say "run where Nix is available" — run them on the Alice target machine or any Linux box with Nix installed; do not block the task on being unable to run them locally. Shell-script logic (credential parsing, `qrencode` invocation) must still be verified locally with plain `bash`, which *is* available.
- AP addressing: gateway `10.0.0.1`, subnet `10.0.0.0/24` (per `docs/alice.md`).
- WiFi interface is configurable via a new `alice.wifiAp.interface` NixOS option, default `"wlan0"` — per-machine hardware config can override it if a given unit's built-in WiFi enumerates differently.

- [ ] **Step 3: Write `nixos/modules/wifi-ap.nix`**

```nix
{ config, pkgs, lib, ... }:

let
  cfg = config.alice.wifiAp;

  hostapdTemplate = pkgs.writeText "hostapd.conf.template" ''
    interface=${cfg.interface}
    driver=nl80211
    ssid=@SSID@
    hw_mode=g
    channel=6
    wpa=2
    wpa_passphrase=@PASSWORD@
    wpa_key_mgmt=WPA-PSK
    rsn_pairwise=CCMP
  '';

  renderHostapdConf = pkgs.writeShellScript "render-hostapd-conf" ''
    set -euo pipefail
    creds="/etc/alice/wifi-credentials"
    if [ ! -f "$creds" ]; then
      echo "Missing $creds — see docs/alice.md install steps" >&2
      exit 1
    fi
    ssid=$(grep -E '^SSID=' "$creds" | cut -d= -f2-)
    password=$(grep -E '^PASSWORD=' "$creds" | cut -d= -f2-)
    if [ -z "$ssid" ] || [ -z "$password" ]; then
      echo "$creds is missing SSID or PASSWORD" >&2
      exit 1
    fi
    mkdir -p /run/hostapd
    sed -e "s/@SSID@/$ssid/" -e "s/@PASSWORD@/$password/" ${hostapdTemplate} > /run/hostapd/hostapd.conf
    chmod 600 /run/hostapd/hostapd.conf
  '';
in
{
  options.alice.wifiAp.interface = lib.mkOption {
    type = lib.types.str;
    default = "wlan0";
    description = "Network interface used for Alice's WiFi access point.";
  };

  config = {
    networking.networkmanager.unmanaged = [ cfg.interface ];

    networking.interfaces.${cfg.interface}.ipv4.addresses = [
      { address = "10.0.0.1"; prefixLength = 24; }
    ];

    systemd.services.hostapd = {
      description = "Alice WiFi access point";
      after = [ "network.target" ];
      wantedBy = [ "multi-user.target" ];
      serviceConfig = {
        Type = "simple";
        ExecStartPre = "${renderHostapdConf}";
        ExecStart = "${pkgs.hostapd}/bin/hostapd /run/hostapd/hostapd.conf";
        Restart = "on-failure";
      };
    };

    services.dnsmasq = {
      enable = true;
      settings = {
        interface = cfg.interface;
        bind-interfaces = true;
        "dhcp-range" = [ "10.0.0.50,10.0.0.150,24h" ];
        "dhcp-option" = [ "3,10.0.0.1" "6,10.0.0.1" ];
      };
    };
  };
}
```

- [ ] **Step 2: Write `nixos/modules/aliases.nix`**

```nix
{ config, pkgs, lib, ... }:

let
  wifiQr = pkgs.writeShellScriptBin "wifi-qr" ''
    set -euo pipefail
    creds="/etc/alice/wifi-credentials"
    out="/home/gallery/wifi-qr.png"
    if [ ! -f "$creds" ]; then
      echo "Missing $creds — see docs/alice.md install steps" >&2
      exit 1
    fi
    ssid=$(grep -E '^SSID=' "$creds" | cut -d= -f2-)
    password=$(grep -E '^PASSWORD=' "$creds" | cut -d= -f2-)
    if [ -z "$ssid" ] || [ -z "$password" ]; then
      echo "$creds is missing SSID or PASSWORD" >&2
      exit 1
    fi
    ${pkgs.qrencode}/bin/qrencode -o "$out" "WIFI:T:WPA;S:$ssid;P:$password;;"
    echo "QR code written to $out"
  '';
in
{
  environment.systemPackages = [ wifiQr pkgs.qrencode ];
}
```
